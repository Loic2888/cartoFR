# Règles d'exhaustivité

Ne jamais annoncer « exhaustif », « complet » ou « terminé » uniquement parce qu'une liste importante a été trouvée.

Une cartographie peut être marquée `complete` uniquement si :

1. les univers officiels de contrôle ont été identifiés ;
2. toutes les entités de ces univers ont un statut explicite ;
3. toutes les branches targetables ont fait l'objet d'une expansion récursive ;
4. les marques officielles sont classifiées et reliées ou explicitement non juridiques ;
5. les relations critiques ont une preuve ;
6. `entities_to_resolve` ne contient plus d'éléments ouverts importants ;
7. les exclusions sont documentées ;
8. les désaccords entre sources sont listés.

Utiliser ces statuts :

- `in_progress`
- `substantially_complete`
- `complete_with_documented_exclusions`
- `complete`

Pour une branche :

- `not_started`
- `discovery_done`
- `identity_resolved`
- `parent_resolved`
- `recursive_expansion_in_progress`
- `recursive_expansion_complete`

Dans le rapport final, séparer explicitement :

- ce qui est confirmé ;
- ce qui est détecté mais non résolu ;
- ce qui est exclu ;
- ce qui reste à rechercher.
